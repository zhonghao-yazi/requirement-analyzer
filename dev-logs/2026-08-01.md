## 启动方式

### 前端
```bash
cd requirement-analyzer
npm run dev     # 开发模式 → http://localhost:5173
npm run build   # 生产构建
```

### 后端
```bash
cd backend
pip install -r requirements.txt
python main.py  # FastAPI → http://localhost:8000
```
