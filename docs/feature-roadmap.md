## 开发路线建议

```
Phase 1 (当前)     Phase 2 (1-2周)       Phase 3 (2-4周)       Phase 4 (长期)
   基线 ✅     →     P0 可用性    →      P1 效率    →      P2-P4 生态
   F01-F20          F21-F24              F25-F29              F30-F48
```

| 阶段 | 目标 | 核心交付 | 预估工作量 |
|------|------|---------|:--------:|
| **Phase 1** | 稳定基线 | 全部已有功能通过测试 | ✅ 已完成 |
| **Phase 2** | 可用产品 | 编辑 + 增删 + 历史记录 | 3-5 天 |
| **Phase 3** | 效率工具 | 搜索 + 批量 + 多格式导出 + 进度 | 5-8 天 |
| **Phase 4** | 专业平台 | 优先级 + 评审 + 统计 + 深色模式 | 按需迭代 |

## 技术债务（需同步关注）

| 编号 | 问题 | 建议 |
|------|------|------|
| T01 | 无 TypeScript 类型覆盖 | 渐进迁移核心模块（先 services/utils，后 components） |
| T02 | 无前端单元测试 | 引入 Vitest + Testing Library |
| T03 | CSS Modules 复用率低 | 抽取公共卡片/按钮/徽章样式为全局 mixin |
| T04 | 后端规则引擎太简陋 | 丰富关键词库 + 引入模板引擎（Jinja2） |
| T05 | 无 CI/CD 流水线 | 接入 GitHub Actions（lint + test + build） |
