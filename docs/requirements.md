# 需求文档 — 需求分析测试用例生成平台

## 产品定位

面向软件测试工程师的轻量级需求分析工具。上传需求文件后，自动提炼需求内容、梳理核心流程，并生成覆盖全面的测试用例表格。

## 核心功能

### F1. 文件上传

- 支持格式：PNG / JPG / GIF / DOCX / PDF / MD / TXT / XMind (.xmind)
- 交互方式：拖拽上传 + 点击选择
- 大小限制：单文件 ≤ 20MB
- 上传后自动触发分析

### F2. 需求分析

- 提取：核心需求点、功能模块、业务规则
- 输出：需求摘要列表（卡片形式）

### F3. 核心流程梳理

- 识别：业务流程节点与流转关系
- 输出：可视化流程图（节点 + 连线）

### F4. 测试用例生成

- 覆盖维度：
  - ✅ 核心流程（Happy Path）
  - 🔲 边界值（Boundary Values）
  - 🔒 安全性（Security）
  - ⚙️ 稳定性（Stability / Reliability）
- 表格字段：
  - 序号
  - 测试标题
  - 前置条件
  - 测试步骤
  - 预期结果

### F5. 导出下载

- 格式：Excel (.xlsx)
- 内容：完整测试用例表格（含分类标签）

## 非功能需求

| 维度 | 要求 |
|------|------|
| 浏览器兼容 | Chrome / Edge / Firefox 最新版 |
| 响应式 | 桌面端为主，平板可读 |
| 主题 | 淡紫色简洁风格 |
| 登录 | 暂不实现 |
